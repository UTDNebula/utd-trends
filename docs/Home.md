# UTD Trends Developer Documentation

Welcome to the **UTD Trends Developer Wiki**.

## Suggesting Documentation Changes

Documentation source files live inside the `docs/` directory of the `utd-trends` repository. Do not edit wiki pages directly through the GitHub web UI; instead, submit changes via a pull request against the `develop` branch. Pushes to `develop` automatically publish to this Wiki via GitHub Actions.
